# Error codes

**English** · [Deutsch](ERRORS.de.md) · [Back to the README](README.md)

All 69 error codes the mower can report. The integration shows them in **Last error message**, in the **Problem** sensor and in the **Error** event.

> [!NOTE]
> The column **Meaning** comes from the Greenworks app. The column **What to do? (tip by Claude)** was written by **Claude (AI)** and is **not official Greenworks information**. If in doubt, ask Greenworks support or check the manual of your mower.

| Code | Meaning | What to do? (tip by Claude) |
|---:|---|---|
| 1 | Collision sensor failure | Possibly a sensor defect. Restart the mower; if it persists, contact Greenworks support. |
| 2 | Collision sensor defect or mower is stuck | Free the mower and check the spot (roots, holes, edges, toys). Fence off problem areas with the boundary wire if needed. |
| 3 | Front collision sensor defect or mower stuck when starting | Free the mower and check the spot (roots, holes, edges, toys). Fence off problem areas with the boundary wire if needed. |
| 4 | Rear collision sensor defect or mower is stuck | Free the mower and check the spot (roots, holes, edges, toys). Fence off problem areas with the boundary wire if needed. |
| 5 | Temporary lifted | Check that nothing lifts the mower (bumps, branches, children, animals). If it happens on flat ground, contact Greenworks support. |
| 6 | Lift sensor defect. Unexpected signal from a lift sensor | Possibly a sensor defect. Restart the mower; if it persists, contact Greenworks support. |
| 7 | Lift sensor defect or mower lifted | Check that nothing lifts the mower (bumps, branches, children, animals). If it happens on flat ground, contact Greenworks support. |
| 8 | Front lift sensor defect or mower lifted when starting | Check that nothing lifts the mower (bumps, branches, children, animals). If it happens on flat ground, contact Greenworks support. |
| 9 | Rear lift sensor defect or mower lifted when starting | Check that nothing lifts the mower (bumps, branches, children, animals). If it happens on flat ground, contact Greenworks support. |
| 10 | Stop button defect | Possibly a sensor defect. Restart the mower; if it persists, contact Greenworks support. |
| 11 | Safety key system error | Restart the mower. If the error comes back, contact Greenworks support. |
| 12 | Tilt sensor defect | Possibly a sensor defect. Restart the mower; if it persists, contact Greenworks support. |
| 13 | Too high inclination | The slope is too steep at this spot. Fence it off with the boundary wire or move the wire. |
| 14 | Mower is upside down | Turn the mower over carefully, check it for damage and restart it. |
| 15 | Too high current or voltage from PSU | Check the power supply of the charging station. If it persists, contact Greenworks support. |
| 16 | No boundary signal detected when starting | Check the charging station has power and its light is on, and that the boundary wire is connected and not broken. |
| 17 | Interference with other installation | Another robotic mower nearby may disturb the signal. Change the loop signal code (see manual). |
| 18 | Guide 1 not found | Check that guide wire 1 is connected to the charging station and not broken. |
| 19 | Guide 2 not found | Check that guide wire 2 is connected to the charging station and not broken. |
| 20 | Front right loop sensor defect | Possibly a sensor defect. Restart the mower; if it persists, contact Greenworks support. |
| 21 | Front left loop sensor defect | Possibly a sensor defect. Restart the mower; if it persists, contact Greenworks support. |
| 22 | Rear loop sensor defect | Possibly a sensor defect. Restart the mower; if it persists, contact Greenworks support. |
| 23 | Communication problem with the charging station | Check that the charging station has power and the mower sits correctly on the contacts. |
| 24 | No communication with communication module | Restart the mower. If the error comes back, contact Greenworks support. |
| 25 | No communication with GNSS module | Restart the mower. If the error comes back, contact Greenworks support. |
| 26 | Weak GNSS signal | Usually temporary (trees, buildings, weather). If it happens often, check the mower's position in the app. |
| 27 | SIM card problem | Problem with the built-in SIM card or mobile network. Restart the mower; if it persists, contact Greenworks support. |
| 28 | Communication problem with cutting MCU | Restart the mower. If the error comes back, contact Greenworks support. |
| 29 | Internal error | Restart the mower. If the error comes back, contact Greenworks support. |
| 30 | Internal error | Restart the mower. If the error comes back, contact Greenworks support. |
| 31 | Internal error. Mower is reset to factory settings | The mower was reset. Check the settings and the schedule in the app and set them again if needed. |
| 32 | Right wheel motor defective | Switch off the mower and check the wheel for grass, mud or objects. Clean it and restart. If it persists, contact Greenworks support. |
| 33 | Right wheel motor overloaded | Usually too steep, too wet or too long grass. Clean the wheel, let the mower cool down and try again later. |
| 34 | Right wheel motor blocked | Switch off the mower and check the wheel for grass, mud or objects. Clean it and restart. If it persists, contact Greenworks support. |
| 35 | Right wheel motor drive system defect | Switch off the mower and check the wheel for grass, mud or objects. Clean it and restart. If it persists, contact Greenworks support. |
| 36 | Left wheel motor defective | Switch off the mower and check the wheel for grass, mud or objects. Clean it and restart. If it persists, contact Greenworks support. |
| 37 | Left wheel motor overloaded | Usually too steep, too wet or too long grass. Clean the wheel, let the mower cool down and try again later. |
| 38 | Left wheel motor blocked | Switch off the mower and check the wheel for grass, mud or objects. Clean it and restart. If it persists, contact Greenworks support. |
| 39 | Left wheel motor drive system defect | Switch off the mower and check the wheel for grass, mud or objects. Clean it and restart. If it persists, contact Greenworks support. |
| 40 | Cutting motor defective | Switch off the mower (gloves!) and check the blade disc for grass, stones or other objects. If it persists, contact Greenworks support. |
| 41 | Cutting motor overloaded | Usually the grass is too long or too wet. Mow it shorter once by hand or raise the cutting height, then try again. |
| 42 | Cutting motor blocked | Switch off the mower (gloves!) and check the blade disc for grass, stones or other objects. If it persists, contact Greenworks support. |
| 43 | Cutting motor drive system defect | Switch off the mower (gloves!) and check the blade disc for grass, stones or other objects. If it persists, contact Greenworks support. |
| 44 | Outside working area | Carry the mower back inside the boundary wire and check that the wire is not broken. |
| 45 | The battery is not compatible with this mower | Only use the original battery for this mower. |
| 46 | Battery communication problem | Check that the battery sits firmly. If it persists, contact Greenworks support. |
| 47 | Battery empty | Carry the mower to the charging station and let it charge. If it happens often, check the way back to the station. |
| 48 | Battery temperature too high | Let the mower cool down in the shade. Avoid mowing in strong midday heat. |
| 49 | Battery temperature too low | Too cold for the battery. Wait until it gets warmer. In winter, store the mower indoors, dry and frost-free. |
| 50 | Battery over-voltage | Restart the mower. If the error comes back, contact Greenworks support. |
| 51 | Battery over-current | Restart the mower. If the error comes back, contact Greenworks support. |
| 52 | Mower has no drive | Switch off the mower and check the wheel for grass, mud or objects. Clean it and restart. If it persists, contact Greenworks support. |
| 53 | Mower is stuck | Free the mower and check the spot (roots, holes, edges, toys). Fence off problem areas with the boundary wire if needed. |
| 54 | Charging station blocked. The mower cannot dock | Remove anything blocking the charging station (grass, leaves, objects) and check the station stands level. |
| 55 | Stuck in charging station | Free the mower from the charging station and check the station for objects and level ground. |
| 56 | Main switch alarm. Mower turned off without PIN code | The mower was switched off without the PIN. Switch it on again and enter the PIN. |
| 57 | Lift sensor alarm. The mower is lifted | The mower was lifted. Check where it is and enter the PIN on the mower. |
| 58 | Geofence alarm. The mower is outside the geofence area | The mower left the geofence area. Check where it is (position in the app). |
| 59 | No boundary signal | Check the charging station has power and its light is on, and that the boundary wire is connected and not broken. |
| 60 | Lost connection to charging station. Loop signal still detected | Check the charging station has power and its light is on, and that the boundary wire is connected and not broken. |
| 61 | No power in charging station | Check the power supply and socket of the charging station. |
| 62 | Interference with loop signal from other installation. Change loop signal code | Another robotic mower nearby disturbs the signal. Change the loop signal code (see manual). |
| 63 | Mower software is updated | Information only, nothing to do. |
| 64 | Mower started with safety key. Press STOP then START on mower | Press STOP and then START on the mower. |
| 65 | Front loop sensor defect | Possibly a sensor defect. Restart the mower; if it persists, contact Greenworks support. |
| 66 | Cutting motor brake defect | Restart the mower. If the error comes back, contact Greenworks support. |
| 67 | Too low charging current | Clean the charging contacts on the mower and the station and check the power supply. |
| 68 | Charging system defect in mower | Restart the mower. If the error comes back, contact Greenworks support. |
| 69 | Week timer enabled, but clock is not set | Open the Schedule page in the app and confirm "Incorrect time" with OK. The mower then gets the correct time from your phone. |
